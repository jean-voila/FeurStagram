About Feurstagram

Feurstagram is a free, open-source Android app based on the official Instagram app. Open-source patches remove the home feed, Reels, Explore, suggested accounts, ads and telemetry, while direct messages, stories, search, profiles and notifications keep working. Each block can be switched on or off from an in-app settings page. The project is developed in the open on GitHub and distributed as an APK through GitHub releases.

Key features

  • Blocks the home feed, Reels (tab and feed), Explore, suggested accounts and ads.
  • Keeps direct messages, stories, search, profiles, notifications, and Reels or posts shared in conversations.
  • Every block is a separate switch, opened by long-pressing the Home tab.
  • Optional “Following feed only” mode: a chronological feed of followed accounts, without recommended posts.
  • Hide any bottom-bar icon and choose which screen the app opens on.
  • Optional permanent lock: blocks can be made stricter but not turned off without reinstalling.
  • In-app updates with release notes.
  • Two builds: one that replaces Instagram, and a clone that installs alongside the official app.

How it works

Feurstagram applies patches to the official Instagram Android APK with the open-source Morphe patcher. The patches locate code by stable traits rather than obfuscated names, so they keep working across Instagram updates. Blocked surfaces are stopped at the network level: requests for the feed, Reels or Explore are refused inside the app, so that content is never downloaded. Analytics and telemetry requests are blocked the same way. The app does not use a proxy server and does not collect user data.
