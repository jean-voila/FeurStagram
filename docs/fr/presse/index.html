Présentation

Feurstagram est une application Android gratuite et open source, construite à partir de l'application Instagram officielle. Des modifications open source retirent le fil d'actualité, les Reels, l'Explorer, les comptes suggérés, les publicités, tandis que les messages privés, les stories, la recherche, les profils et les notifications continuent de fonctionner. Chaque blocage s'active ou se désactive depuis une page de réglages intégrée. Le projet est développé publiquement sur GitHub et distribué sous forme d'APK via les versions GitHub.

Fonctionnalités principales

  • Bloque le fil d'actualité, les Reels (onglet et fil), l'Explorer, les comptes suggérés et les publicités.
  • Conserve les messages privés, les stories, la recherche, les profils, les notifications, ainsi que les Reels et publications partagés en conversation.
  • Chaque blocage est un interrupteur séparé, accessible depuis une icône Feurstagram en haut de votre profil.
  • Mode « fil limité aux abonnements » : un fil chronologique des comptes suivis, sans publications recommandées.
  • Possibilité de masquer n'importe quelle icône de la barre du bas et de choisir l'écran d'ouverture.
  • Verrou permanent optionnel : les blocages peuvent être renforcés mais pas désactivés sans réinstaller.
  • Mises à jour intégrées, avec notes de version.
  • Deux versions : l'une remplace Instagram, l'autre (clone) s'installe à côté de l'application officielle.

Fonctionnement

Feurstagram applique des modifications à l'APK Instagram officiel pour Android grâce à l'outil open source Morphe. Ces modifications repèrent le code par des caractéristiques stables plutôt que par des noms obfusqués, ce qui leur permet de survivre aux mises à jour d'Instagram. Les requêtes du fil, des Reels et d’Explorer utilisent le transport natif Instagram. Les réponses réussies sont filtrées localement pour masquer les contenus bloqués. Les requêtes natives de statistiques et de télémétrie restent actives. Cela consomme davantage de données API que les anciennes versions et ne garantit pas d’éviter les restrictions de compte. L'application n'utilise aucun serveur intermédiaire et ne collecte aucune donnée.
